How it works

A LaTeX PDF marks its formulas with dedicated math fonts. The tool uses that to translate the prose and leave the mathematics alone.

  1. Read the page

    Every piece of text is sorted by its font. Math fonts such as CMMI and CMSY mark formulas. Text fonts mark prose.

    Soit une fonction continue sur .

  2. Translate the prose

    Each formula is replaced by a placeholder, so the translator only ever sees words.

    Let {M0} be a continuous function on {M1}.

  3. Typeset it again

    The translation is set in Computer Modern on the original page, and every formula returns to its place.

Translation engines

Google Translate works without an account. The other engines use your own API key, and two local models run on your own computer through the command-line tool.

Engine What you need Available on
Google Translate Nothing Website and command line
DeepL API key, 500,000 characters a month free Website and command line
Azure Translator API key and region, 2 million characters a month free Website and command line
Google Cloud Translation API key Website and command line
Claude Anthropic API key Website and command line

Apple on-device model macOS 26 with Apple Intelligence Command line

Command line

The command-line tool has no page limit and can use the local models. It needs uv. 

$ git clone https://github.com/joshuaswanson/latex-pdf-translator
$ cd latex-pdf-translator

# Translate a French paper to English
$ uv run main.py paper.pdf --source fr

# Use a local model, with Google for anything it misses
$ uv run main.py paper.pdf --source de --engine ollama --fallback google
